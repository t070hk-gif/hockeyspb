# ВСЕССЫЛКИ.СПБ — боты детского хоккея Санкт-Петербурга

Автоматически ведёт группу ВСЕССЫЛКИ.СПБ в Telegram: расписание и результаты
матчей, видео трансляций из VK, турнирные таблицы.

## Что из чего состоит

| Файл | Что делает | Как запускается |
|---|---|---|
| `post_schedule.py` | Посты дня по турнирам: расписание, видео, результаты; баннер с результатами (голы, передачи, вратари, штрафы, ОТ/ПБ) | cron, каждые 2 мин |
| `live_watcher.py` | Живой счёт и голы во время матчей | cron, каждую минуту |
| `post_standings.py` | Турнирные таблицы (по группам — альбомом), вечерняя перепубликация | cron, каждые 10 мин |
| `vk_to_tg_hockey_bot.py` | Находит трансляции в группах VK, привязывает к матчам; товарищеские игры; ручная привязка через личку бота | launchd, постоянно |
| `health_check.py` | Предупреждения о сбоях и вечерняя сводка в личку | cron, каждые 10 мин |
| `rotate_logs.sh` | Архивирует логи больше 10 МБ | cron, 04:10 |

Вспомогательные модули: `team_matcher.py` (сопоставление видео с расписанием),
`spb_fhr_client.py` и `spb_protocol.py` (данные spb.fhr.ru), `results_banner.py`
(баннер с результатами), `generate_banner_v2.py` (баннеры турниров).

Источники данных: fhspb.ru — расписание, результаты, таблицы Первенства;
spb.fhr.ru — протоколы, голы, живой счёт; запасной источник постов дня,
если fhspb.ru недоступен.

## Настройки

Токен бота, группа и ваш Telegram ID — в `config.json` (в git не хранится).
Образец — `config.example.json`. Доступ к VK — бессрочный ключ, см. раздел «Ключ VK» ниже.

## Ключ VK (чтобы токен не «вылетал»)

Раньше бот работал с пользовательским токеном VK ID (`vk_tokens.json`). Он живёт около
часа и продлевается через одноразовый `refresh_token`; стоит двум копиям бота (MacBook,
резервный компьютер, облако) продлить один и тот же токен, или отозвать вход в VK —
и токен перестаёт работать до ручной авторизации. Теперь бот использует **сервисный ключ
приложения** VK (или **токен сообщества**): он бессрочный, без входа и без продления.

**Где взять ключ**

1. Сервисный ключ приложения: откройте настройки вашего VK-приложения (то же, чей
   `client_id` в `get_vk_token.py`; приложения — <https://vk.com/apps?act=manage> или
   кабинет VK ID <https://id.vk.com/about/business/go>) → раздел «Ключи доступа» →
   «Сервисный ключ доступа». Скопируйте его целиком.
2. Запасной вариант — токен сообщества: страница своего сообщества VK → «Управление» →
   «Настройки» → «Работа с API» → «Ключи доступа» → «Создать ключ» (права: стена, видео).
   Бессрочный, пока вы его не удалите.

**Куда прописать** (достаточно одного места; переменная окружения важнее файла):

- в `config.json` рядом с ботом: `"vk_service_key": "<ключ>"` (файл в git не хранится,
  при резервировании уезжает на другие компьютеры и в облако зашифрованным);
- либо переменная окружения `VK_SERVICE_KEY` (для облака GitHub Actions —
  секрет репозитория `VK_SERVICE_KEY`: Settings → Secrets and variables → Actions).

Ключ нигде не пишите в код, чат и коммиты. Потом перезапустите бота (`./restart_vkbot.sh`)
и проверьте ключ:

```bash
python3 check_vk_key.py   # покажет, какие методы VK пропускает этот ключ
```

Если ключ неверный или отозван, бот не падает в цикле: в лог пишет понятную причину
(`[VK AUTH] …`), раз в час шлёт вам сообщение в Telegram и сам подхватывает исправленный
`config.json` в течение минуты. Пока `vk_service_key` пуст, работает старая схема с
`vk_tokens.json` (`python3 get_vk_token.py`); после перехода файл можно удалить.

**Ограничения сервисного ключа и токена сообщества.** Боту нужны методы `wall.get`,
`video.get` (каталог группы и проверка по id) и `groups.getById` — по документации VK
они доступны с сервисным ключом и ключом сообщества. Ограничено то, чего нет у
«анонимного читателя»: закрытые и приватные сообщества, видео и записи с ограниченной
приватностью, всё «от имени пользователя». Если какая-то из отслеживаемых групп закрыта
или часть видео пропала из выдачи, `check_vk_key.py` и строки `[VK API error …]` в логе
покажут, на каком методе отказ. Для таких групп сервисный ключ не подойдёт: либо уберите
их из `VK_GROUP_IDS`, либо вернитесь на пользовательский токен (очистите `vk_service_key`,
нужен `vk_tokens.json`). Лимит
сервисного ключа — 3 запроса в секунду на приложение; бот сам держит паузу между запросами.

## Полезные команды

```bash
python3 tests/run_all.py                 # автотесты — перед и после любых изменений
python3 check_vk_key.py                  # проверить VK-ключ и доступные ему методы
python3 why_no_video.py [ДД.ММ.ГГГГ]     # почему у матча нет видео в посте
python3 audit_missing_videos.py --days 3 # поиск трансляций для матчей без видео (--apply — записать)
python3 health_check.py --report         # состояние системы и сводка за сегодня
python3 force_repost_standings.py --now  # перепубликовать все таблицы
```

Ручная привязка видео: пришлите ссылку на трансляцию боту в личку — он найдёт
матч сам или задаст вопросы (команды, дата, время, возраст; «+» — оставить
подсказку, «-» — не знаю, «отмена» — прервать).
