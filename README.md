# ВСЕССЫЛКИ.СПБ — боты детского хоккея Санкт-Петербурга

Автоматически ведёт группу ВСЕССЫЛКИ.СПБ в Telegram: расписание и результаты
матчей, видео трансляций из VK, турнирные таблицы.

## Что из чего состоит

| Файл | Что делает | Как запускается |
|---|---|---|
| `post_schedule.py` | Посты дня по турнирам: расписание, видео, результаты; баннер с результатами (голы, передачи, вратари, штрафы, ОТ/ПБ) | cron, каждые 2 мин |
| `live_watcher.py` | Живой счёт и голы во время матчей | cron, каждую минуту |
| `post_standings.py` | Турнирные таблицы (по группам — альбомом), вечерняя перепубликация | cron, каждые 10 мин |
| `vk_to_tg_hockey_bot.py` | Находит трансляции в группах VK, привязывает к матчам; товарищеские игры; ручная привязка через личку бота | launchd, постоянно |
| `health_check.py` | Предупреждения о сбоях и вечерняя сводка в личку | cron, каждые 10 мин |
| `rotate_logs.sh` | Архивирует логи больше 10 МБ | cron, 04:10 |

Вспомогательные модули: `team_matcher.py` (сопоставление видео с расписанием),
`spb_fhr_client.py` и `spb_protocol.py` (данные spb.fhr.ru), `results_banner.py`
(баннер с результатами), `generate_banner_v2.py` (баннеры турниров).

Источники данных: fhspb.ru — расписание, результаты, таблицы Первенства;
spb.fhr.ru — протоколы, голы, живой счёт; запасной источник постов дня,
если fhspb.ru недоступен.

## Настройки

Токен бота, группа и ваш Telegram ID — в `config.json` (в git не хранится).
Образец — `config.example.json`. Токены VK — в `vk_tokens.json`
(обновить: `python3 get_vk_token.py`).

## Полезные команды

```bash
python3 tests/run_all.py                 # автотесты — перед и после любых изменений
python3 why_no_video.py [ДД.ММ.ГГГГ]     # почему у матча нет видео в посте
python3 audit_missing_videos.py --days 3 # поиск трансляций для матчей без видео (--apply — записать)
python3 health_check.py --report         # состояние системы и сводка за сегодня
python3 force_repost_standings.py --now  # перепубликовать все таблицы
```

Ручная привязка видео: пришлите ссылку на трансляцию боту в личку — он найдёт
матч сам или задаст вопросы (команды, дата, время, возраст; «+» — оставить
подсказку, «-» — не знаю, «отмена» — прервать).

## История и откат

Все изменения кода — в git:

```bash
git log --oneline                         # история
git diff                                  # что изменилось с последнего снимка
git checkout HEAD~1 -- post_schedule.py   # вернуть файл к предыдущему снимку
```

Старые скрипты-патчи и отладочные файлы — в `archive/`.
